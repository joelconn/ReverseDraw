How It Works

ReverseDraw is a reverse-lottery style draw app. Tickets are drawn one at a time and eliminated from the pool. The last ticket(s) remaining win the prize. The event runs through five phases in order:

  1. 1Setup — Configure your event name, ticket count, prize amounts, and special draw prizes. Import your guest list CSV if you have one.
  2. 2Main Draw — Draw tickets one at a time. Each draw is shown on the Audience screen. Mark a ticket "Not Present" to void it and carry the prize forward.
  3. 3Final Ten — Begins automatically after the Main Draw threshold. Eliminate contestants one by one, then press Split Pot to divide the prize among all remaining contestants.
  4. 4Bonus Draw — All tickets re-enter the pool. Draw one ticket for the grand prize. If the winner is not present, draw again.
  5. 5Complete — The event is finished and archived automatically. Start a new event from the Setup screen.

Preparing Your Guest List

Create a .csv file with the following format (one row per ticket):

TicketNumber,Name,SponsorLevel
101,Jane Smith,Gold
102,John Doe,Silver
103,Alice Brown,

SponsorLevel is optional — leave it blank if not applicable. Import from the Setup screen before starting the event.

During the Main Draw

  • Draw Next Ticket — Draws a random ticket and shows it on the Audience screen. Press again to dismiss the reveal and enable the next draw.
  • Not Present — Marks the last drawn ticket as absent. The ticket is voided and any special prize carries over to the next draw position.
  • Undo — Reverses the last draw. You can undo multiple draws in sequence.

During the Final Ten

  • Draw Elimination — Randomly eliminates one contestant. The prize split updates live.
  • Not Present (menu) — Opens a list of contestants. Tap one to eliminate them manually if they are not present.
  • Split Pot — Divides the Final Ten prize equally among all remaining contestants. You can split with any number remaining.

External Display / Projector

Connect your Mac or iPad to a projector or external display before launching ReverseDraw. The Audience screen will automatically appear on the connected display. On Mac, if the Audience window closes, press the split-screen icon in the top-left of the Operator screen to reopen it.

Keyboard Shortcuts

Space Draw next ticket / dismiss reveal
⌘Z Undo last draw

Common Questions

The app crashed mid-draw. Did I lose my progress?
No. ReverseDraw saves automatically after every action. Relaunch and choose Resume on the Setup screen to pick up where you left off.

Can I undo a draw?
Yes — use the Undo button in the Operator window (or ⌘Z) to reverse the most recent draw.

Where is my data stored?
All data is stored locally on your device. Nothing is sent to the internet.

What devices does ReverseDraw support?
ReverseDraw runs on Mac and iPad. Connect an external display or projector to either device for the two-screen experience.
